# EFA TECHNOLOGIE — Site Vitrine Officiel

> **« EFA Tech, la facilité de la technologie »**

Site vitrine officiel de l'entreprise technologique togolaise **EFA TECHNOLOGIE**, présentant son écosystème d'applications de gestion d'entreprise conçues pour le Togo et l'Afrique :

1. **EFA ACONTA** — Comptabilité et gestion de trésorerie simplifiées en Francs CFA (XOF).
2. **EFA SUITE** — Application 2-en-1 comprenant **EFA Facture** (facturation certifiée OTR) et **EFA Mon prix** (calculateur de prix et de marges pour vendre sans perdre).
3. **EFA GARDE** — Repérage facile des pharmacies de garde autour de vous à Lomé et contact direct avec ces pharmacies.

- **Design Premium Apple / Stripe** : Typographie raffinée (Plus Jakarta Sans & Sora), palette officielle Bleu EFA (`#0A3D8F`), Bleu ciel (`#E8F1FF`), Blanc et Gris doux.

## 🛠️ Stack Technique

- **Framework** : React 19 + TypeScript + Vite
- **3D Engine** : Three.js (avec `RoomEnvironment` et `ACESFilmicToneMapping`)
- **Styling** : Tailwind CSS v4
- **Icones** : Lucide React

## 📦 Déploiement

### 1. Pousser sur GitHub (`efa-technologie`)

```bash
git init
git add .
git commit -m "Initial commit - Site officiel EFA TECHNOLOGIE"
git branch -M main
git remote add origin https://github.com/VOTRE_COMPTE/efa-technologie.git
git push -u origin main
```

### 2. Déployer sur Vercel

Le fichier `vercel.json` est déjà configuré à la racine pour la compilation Vite et la distribution directe des fichiers APK.
Importez simplement votre dépôt GitHub `efa-technologie` sur [vercel.com](https://vercel.com) pour un déploiement instantané.
